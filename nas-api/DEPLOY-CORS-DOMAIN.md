2. ไปที่ `web` → `api`
3. ลากทั้ง 4 ไฟล์จาก `nas-api/` เข้าไปวาง

## ตรวจว่าสำเร็จ

รันจากเครื่องที่มี curl — ทั้ง 3 บรรทัดต้องขึ้น `ผ่าน`

```sh
for e in upload.php telegram-notify.php "oil-proxy.php?p=ptt"; do
  r=$(curl -sS -m 25 -D - -o /dev/null -X OPTIONS \
        -H "Origin: https://subcontractor.neosiamcrm.com" \
        -H "Access-Control-Request-Method: POST" \
        "https://neosiam.dscloud.biz/api/$e" 2>/dev/null \
      | grep -ic "access-control-allow-origin")
  echo "${e%%\?*}: $([ "$r" -gt 0 ] && echo ผ่าน || echo ยังถูกบล็อก)"
done
```

หรือทดสอบจากของจริง: เปิด `https://subcontractor.neosiamcrm.com` →
เปิดงานที่ยังไม่จบ → แนบรูป → กดยืนยันจบงาน → ต้องขึ้นว่าสำเร็จ

**ถ้ายังไม่ผ่าน** ให้ล้างแคชเบราว์เซอร์ (`Ctrl + F5`) ก่อน เพราะเบราว์เซอร์
จำผลของ CORS preflight ไว้ได้สักพัก

## ทำไมต้องมี allowlist

CORS กันได้แค่เบราว์เซอร์ ไม่ได้กัน `curl` หรือสคริปต์ — ด่านจริงคือ API key
แต่ยังต้องมีไว้ เพื่อไม่ให้เว็บอื่นเรียก NAS ของเราจากเบราว์เซอร์ของผู้ใช้ได้

**เวลาเพิ่มโดเมนใหม่ให้ระบบนี้ ต้องเพิ่มทั้ง 4 ไฟล์เสมอ** ไม่ใช่แค่ `upload.php`
